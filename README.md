# Square Clicker

Jogo clicker feito com Pygame. Clique no quadrado para ganhar pontos e compre upgrades:

- **E** → 2X Points
- **D** → Automation
- **G** → Golden Click / Clique Dourado (10 levels, +5% chance per level of a golden click: double points, golden square and message for 5s)

## Rodar direto

```
pip install -r requirements.txt
python main.py
```

## Instalador macOS (.dmg)

Na aba **Actions** do GitHub, abra **Build macOS Installer** → **Run workflow**.
Ao terminar, baixe o `SquareClicker-macOS` em *Artifacts*, abra o `.dmg` e arraste o app para Applications.

Obs.: o app não é assinado pela Apple. No primeiro uso, clique com o botão direito no app → **Abrir**.
